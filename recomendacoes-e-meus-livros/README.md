# Recomendações e Meus Livros

Esta pasta reúne as telas funcionais de **Meus livros**, **Recomendações** e os detalhes exibidos ao clicar em um livro.

## Arquivos principais

- `meus-livros.php` — estante do usuário e seus livros.
- `recomendacoes.php` — lista de livros recomendados.
- `livro.php` — detalhes do livro selecionado; recebe o identificador pela URL, por exemplo `livro.php?id=1`.

## Pastas de apoio

- `assets/css/` — estilos compartilhados pelas telas.
- `assets/js/` — interações da página.
- `dados/` — dados de demonstração usados enquanto não há integração com o backend.
- `includes/` — cabeçalho e cartão de livro reutilizados nas páginas.

Os links entre estas páginas são locais a esta pasta. A equipe pode conectá-los às rotas definitivas do projeto quando fizer a integração.
